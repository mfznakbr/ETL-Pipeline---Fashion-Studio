
1. Cara Menjalankan Script ETL Pipeline

Untuk menjalankan script ETL pipeline yang telah dibangun, ikuti langkah-langkah berikut:

a. Aktifkan Virtual Environment  
   Pastikan kamu sudah mengaktifkan virtual environment yang telah disiapkan untuk proyek ini. Jalankan perintah berikut di terminal:
   
   .\.env\Scripts\activate
   

b. Install Dependencies
   Install semua dependencies yang diperlukan dengan menjalankan:
   
   pip install -r requirements.txt
   

c. Jalankan Script ETL Pipeline  
   Setelah mengaktifkan environment dan menginstal dependencies, jalankan script utama ETL dengan perintah berikut:
   
   python main.py
   
   Script ini akan melakukan tahapan Extract, Transform, dan Load. Data produk fashion akan diambil dari website, diproses (membersihkan dan mengubah format), lalu disimpan ke dalam file CSV, Google Sheets, dan PostgreSQL.


2. Cara Menjalankan Unit Test

Unit tests dapat dijalankan menggunakan `pytest`. Ikuti langkah-langkah berikut untuk menjalankan unit test:

a. Jalankan Unit Test  
   Setelah mengaktifkan virtual environment, jalankan perintah berikut untuk menjalankan unit test:
   
   pytest
   
   Unit test ini akan menguji setiap bagian dari proses ETL untuk memastikan bahwa semuanya berjalan dengan benar.

---

3. Cara Menjalankan Test Coverage

Untuk menjalankan test coverage dan mendapatkan laporan, gunakan perintah berikut setelah mengaktifkan virtual environment:

a. Jalankan Test Coverage  
   Untuk menjalankan coverage dan melihat hasilnya di terminal, jalankan:
   
   pytest --cov=utils --cov-report=term
   
   Laporan coverage akan menunjukkan bagian-bagian kode yang telah diuji dan seberapa lengkap cakupan pengujian tersebut.

   Jika ingin menyimpan laporan coverage ke dalam file, kamu bisa menggunakan:
   
   pytest --cov=utils --cov-report=term > coverage_report.txt
